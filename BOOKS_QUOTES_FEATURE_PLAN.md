# Books & Quotes Feature — Implementation Plan

## Overview
Replace the AI motivation generator in `DailyNotesView` and the "Why Statement" purpose generator in the task detail (TasksCalendarView) with a **Books library** system. Users create Book entities, generate quotes from AI, store them, and activate up to 2 books whose quotes cycle every 10 seconds in both views.

## New Data Models (SwiftData)

### `Book`
```swift
@Model class Book {
    var id: UUID
    var title: String
    var author: String
    var isActive: Bool        // Up to 2 can be active at once
    var createdAt: Date

    @Relationship(deleteRule: .cascade, inverse: \BookQuote.book)
    var quotes: [BookQuote]? = []
}
```

### `BookQuote`
```swift
@Model class BookQuote {
    var id: UUID
    var text: String          // The actual quote
    var source: QuoteSource   // .ai or .manual
    var createdAt: Date
    var book: Book?
}

enum QuoteSource: String, Codable {
    case ai       // Generated by OpenAI
    case manual   // Added by the user
}
```

## New Files to Create

### 1. `FocusFlowSwift/Models/BookQuoteManager.swift`
An `@Observable` / `ObservableObject` singleton class:
- Holds `currentQuote: BookQuote?`
- Holds `currentQuoteIndex: Int`
- Has a 10-second `Timer` that advances to next quote
- Pulls quotes from all active books' saved quotes (not AI)
- Provides `startCycling()` / `stopCycling()` methods
- Transitions: uses a flag (`showingQuote: Bool`) to drive `.transition(.opacity)` / `.slide` animations
- Used by both `DailyNotesView` and task detail in `TasksCalendarView`

### 2. `FocusFlowSwift/Models/BookQuoteService.swift`
AI service for quote generation:
- Mirrors `OpenAIService` pattern (URLSession + OpenAI API, reads from Config.xcconfig)
- Function: `generateQuotes(for book: Book, existingQuotes: [String], count: Int = 25) async throws -> [String]`
- System prompt instructs model to return **exactly 25** quotes as a JSON array of strings
- Prompt includes book title + author, and the list of existing quote texts to avoid duplicates
- Parses JSON response and returns `[String]`
- Model: `gpt-3.5-turbo` (consistent with existing usage)

### 3. `FocusFlowSwift/Views/BooksView.swift`
Main books library screen:
- `NavigationView` with list of all `Book` entities
- Each row shows: title, author, quote count, active badge
- Activate/deactivate toggle per book (enforces max 2 active)
- Swipe to delete a book
- "+" toolbar button → shows `AddBookView` sheet
- Tap a book row → navigates to `BookDetailView`

### 4. `FocusFlowSwift/Views/BookDetailView.swift`
Individual book screen:
- Header: book title, author
- Quote count badge (total, with breakdown: X AI · Y manual)
- Two action buttons side by side:
  - **"Generate 25 Quotes"** (AI) — disabled while loading; calls `BookQuoteService`, deduplication enforced
  - **"Add My Own Quote"** — opens `AddManualQuoteView` sheet
- Loading spinner with "Generating quotes..." text
- List of all saved quotes for this book (scrollable), sorted newest first
  - Each quote cell shows:
    - Quote text
    - Small badge: `AI` (blue) or `Manual` (green) indicating source
    - Creation date in secondary text
  - Swipe to delete individual quotes
- "Generate More" button at bottom of quote list (same AI behaviour, deduplication enforced)

### 5. `FocusFlowSwift/Views/AddBookView.swift`
Simple sheet for creating a book:
- `TextField` for title
- `TextField` for author
- Cancel / Save buttons
- On save: creates `Book`, inserts, saves context

### 5b. `FocusFlowSwift/Views/AddManualQuoteView.swift`
Sheet for adding a user-written quote to a book:
- Large multiline `TextEditor` for the quote text
- Character count hint (e.g. min ~10 chars to prevent empty saves)
- Cancel / Save buttons
- On save: creates `BookQuote(text:, source: .manual)`, inserts into modelContext, saves
- Duplicate check: if the exact text already exists in this book (case-insensitive), shows inline warning and blocks save

### 6. `FocusFlowSwift/Views/BookQuoteDisplayView.swift`
Reusable component used in both `DailyNotesView` and `TasksCalendarView`:
- Observes `BookQuoteManager`
- If no active books / no quotes: shows `"Activate a book in the Books library to see quotes here"` placeholder
- If quotes exist: displays current quote text + book title/author attribution
- Transitions: `.asymmetric(insertion: .move(edge: .trailing).combined(with: .opacity), removal: .move(edge: .leading).combined(with: .opacity))`
- Starts/stops cycling timer via `onAppear` / `onDisappear`

## Activation Logic (Max 2 Active Books)
- When toggling a book to active:
  - Count currently active books
  - If already 2 active, show alert: `"You can only activate 2 books at a time. Deactivate one first."`
  - If fewer than 2, allow activation
- `BookQuoteManager` reloads its quote pool whenever the view refreshes or `Book.isActive` changes

---

## Quote Display Logic
- `BookQuoteManager` holds a flat array built from: `activeBooks.flatMap { $0.quotes ?? [] }.shuffled()`
- Timer fires every 10 seconds → increments index (wraps around)
- Quotes rotate only through **saved** `BookQuote` entities — never calls AI at display time
- If pool is empty: `currentQuote = nil` → `BookQuoteDisplayView` shows placeholder

---

## Duplicate Prevention

### AI-generated quotes
- Before generating: collect all existing `quote.text` strings for that book (both AI and manual)
- Include them in the AI prompt: `"Do not repeat any of these existing quotes: [list]"`
- After generation: filter response array to exclude any text already in the model (case-insensitive trim comparison)
- Only insert truly new quotes

### Manual quotes
- On save in `AddManualQuoteView`: check case-insensitive trimmed match against all existing quote texts for the book
- If a match is found: show inline warning `"This quote already exists in this book"` and keep Save disabled until text is changed
- No partial-match fuzzy check — exact normalised string equality is sufficient
