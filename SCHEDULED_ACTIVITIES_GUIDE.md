# Scheduled Activities Feature

The Scheduled Activities feature replaces the previous fasting functionality with a more flexible system for managing time-based activities with specific windows.

## How It Works

### Creating a Scheduled Activity

1. Navigate to the "Activities" tab (clock with checkmark icon)
2. Tap the "+" button to create a new activity
3. Enter an activity name (e.g., "Instagram", "Social Media Break", "Coffee Break")
4. Add scheduled times by tapping "Add Time" and selecting specific times
5. Set the window duration (how long the window stays open)
6. Tap "Create Activity"

### Example Setup: Instagram 3 Times a Day

- **Activity Name**: Instagram
- **Scheduled Times**: 9:00 AM, 1:00 PM, 5:00 PM
- **Window Duration**: 10 minutes

### Using the Feature

1. **Countdown Phase**: Between scheduled times, you'll see a countdown to the next window
2. **Active Window**: When a scheduled time arrives, the window opens and shows:
   - A countdown timer showing remaining window time
   - A "Use Window" button to access the activity
3. **Activity Window**: When you tap "Use Window":
   - Full-screen activity interface with countdown
   - Optional notes field to record what you did
   - "Mark as Used" button to log the usage
4. **History Tracking**: All usage is automatically logged with timestamps and notes

### Key Features

- **Multiple Daily Windows**: Set up to 4 (or more) times per day
- **Flexible Timing**: Any time of day with minute precision
- **Automatic Windows**: Windows open and close automatically based on your schedule
- **Usage Tracking**: Complete history of when you used each window
- **Notes Support**: Add notes about what you did during each session
- **Visual Countdown**: Always see time until next window or time remaining in current window

### Benefits

- **Structured Usage**: Control when you can access certain activities
- **Time Awareness**: Visual feedback on remaining time
- **Usage Insights**: Track patterns and frequency of activity usage
- **Discipline Building**: Clear boundaries with automatic enforcement
- **Flexibility**: Easy to modify schedules and window durations

### Managing Activities

- **View All Activities**: See all your scheduled activities with their next window times
- **Edit Activities**: Modify times, duration, or disable activities
- **Usage History**: Review past usage with filtering by day, week, month, or all time
- **Activity Status**: Clear indication of active windows vs countdown periods

This system is perfect for managing social media usage, break times, or any activity where you want structured, time-limited access with automatic tracking.
